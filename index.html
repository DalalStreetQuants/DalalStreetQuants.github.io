3Download & Install Your Bot
  • Download your bot version (.ex5 file) from the Download section above
  • Double-click the downloaded file to add it to MetaTrader
  • Find your bot (dsq_grid_v2, dsq_grid_v3, or dsq_grid_v4) in the Navigator panel under Expert Advisors
2Download MT5 & Login
  • Download MT5 from metatrader5.com
  • Login with your broker credentials (use Cent account only with maximum leverage set like 1:2000)
  • In MetaTrader, go to Tools → Options → Experts:
    • Allow Algorithmic Trading
    • Allow Web Request for listed URL → Add: https://raw.githubusercontent.com
